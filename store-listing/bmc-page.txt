ABOUT ME
=====================================================================
The name I go by online is [handle]. [Real first name, if you want it here.] I live in
[city, country].

I build small tools for myself, mostly the kind that keep other people's software out of my
business: a cleaner that deletes the browser history entries you choose, a search instance that
runs on my own machine, filters and blocklists, a phone with the tracking taken out. Most of them
never leave my own computers. This one did, because the problem it solves is not mine alone.

The extension started because every history cleaner I tried wanted something from me: an account,
an upsell, a permission list I could not justify to myself. So the rule got written before the
code. No server, no account, no analytics, nothing stored anywhere except your own computer.
Everything since has been me holding that line.

What I want from software is simple: it should explain itself, and it should say where it stops.
Half the arguments I have with myself about this project are about the wording, not the code.
