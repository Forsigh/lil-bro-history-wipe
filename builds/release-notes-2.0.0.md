Export is a full setup file now. It always carried your list and your settings; it also
carries the counted numbers, so loading it into a fresh install brings back the whole
picture instead of most of it. A file from an older version still loads, it just has no
counts in it.

While the lock is on, the Logs tab asks for the PIN right where you click it. The box sits
over the page, a wrong guess costs the same there as anywhere else, and the popup says
plainly that the list and the log are out of sight instead of offering a tab that cannot
open.

And a pass over the wording in both languages: English and Polish read more like a person
explaining a thing and less like a settings file talking to itself. No new permissions,
nothing that leaves the computer, same as before.
